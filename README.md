# GOLF GUTS CAMERA

GOLF GUTS 専用のカメラアプリです（iPhone の Safari で動く Web アプリ / PWA）。
撮影した動画に GOLF GUTS のロゴを自動で焼き込み、共有メニューから iPhone の「写真」アプリへ保存します。

- バージョン: 1.6.0
- 撮影データはすべて iPhone の中だけで処理します。外部サーバーへは送信しません。
- 外部ライブラリは使っていません（Web 標準機能のみ）。

---

## 1. 使い方

1. アプリを開く（カメラとマイクの許可を求められたら「許可」）
2. 赤いボタンで録画開始
3. もう一度押して停止 → 共有メニューが自動で開く
4. 共有メニューで「ビデオを保存」を選ぶ
5. 「‹ 撮影に戻る」で次の撮影へ

共有メニューを閉じてしまった場合や自動で開かなかった場合は、確認画面の「写真に保存」を押してください。

- 画面下の「写真 / ビデオ」でモード切り替え、撮影ボタンの左のボタンでイン / アウトカメラ切り替え
- 「.5 / 1×」のボタンで超広角（0.5×）と標準（1×）を切り替え（アウトカメラのみ。超広角に対応していない機種ではボタンは表示されません。録画中はボタンを隠します）
- 映像の上を 2 本指で広げる / つまむ（ピンチ）と、0.5×〜1× の間を連続してズームできます。現在の倍率はボタンに「0.7×」のように表示されます
- 横向きの動画を撮るときは、画面左上の「縦向き」ボタン（白）を押して「横向き」（黄色）にしてから、**本体の上側を左に向けて**横に構えます（「画面縦向きのロック」はオンのままで構いません）。もう一度押すと「縦向き」に戻ります。画面のロゴが正しい向きに見えていれば、その向きで保存されます
- 選んだ向きは、アプリを開き直しても覚えています。縦で撮るときは「縦向き」に戻してください
- 画面右上の「ガイド線」ボタンで、構図の補助線（中央の縦線・対角線・頭の線・足元の線）を表示 / 非表示にできます。**ガイド線は画面に見えるだけで、保存される動画や写真には入りません。** 縦動画では、スイング解析の画面で下のボタンに隠れない範囲（上から 86%）を枠として線を引いています。表示 / 非表示の状態は次回も覚えています
- 画面上部の「GOLF GUTS CAMERA」をタップすると、バージョン・解像度・ロゴの登録状況などを確認できます

## 3. iPhone だけで公開する手順

> GitHub の画面表示は時期により変わることがあります。ボタン名が少し違う場合は近い名前のものを選んでください。
> 操作は GitHub アプリではなく **Safari** で行ってください。

### 3-1. ファイルを iPhone に用意する
1. 受け取った `golf-guts-camera.zip` を「ファイル」アプリに保存する
2. 「ファイル」アプリで zip をタップすると、同じ場所に `golf-guts-camera` フォルダができる

### 3-2. GitHub に登録する
1. Safari で https://github.com を開き、アカウントを作成（Sign up）またはログインする
2. 右上の「＋」→「New repository」
3. Repository name に `lesson-camera` と入力（半角英数字。これが公開アドレスの一部になります）
4. 「Public」を選ぶ（無料プランで GitHub Pages を使うには Public が必要です）
5. 「Create repository」を押す
6. 表示されたページ内の「uploading an existing file」というリンクを押す
7. 「choose your files」→「ファイルを選択」→ `golf-guts-camera` フォルダを開き、**中のファイルをすべて選択**して「開く」
8. 下の「Commit changes」を押す

### 3-3. 公開する（GitHub Pages）
1. リポジトリ画面の「Settings」を開く（見当たらないときは「…」や横スクロールの中にあります）
2. 左メニュー（またはメニュー一覧）の「Pages」を開く
3. 「Source」を「Deploy from a branch」にする
4. 「Branch」を「main」、フォルダを「/ (root)」にして「Save」
5. 1〜3 分待つと、同じ画面の上部に公開アドレスが表示されます
   `https://（あなたのユーザー名）.github.io/lesson-camera/`

### 3-4. ホーム画面に追加する
1. 公開アドレスを **Safari** で開く
2. カメラとマイクの許可を求められたら「許可」
3. 共有ボタン（□に↑）→「ホーム画面に追加」→ 名前が「GUTS CAMERA」になっていることを確認して「追加」
4. ホーム画面のアイコンから起動する（初回はもう一度カメラの許可を求められます）

## 4. ロゴの登録

1. ロゴ画像を用意する（**背景が透明な PNG** を推奨。横幅 1000px 前後あれば十分きれいです）
2. 「ファイル」アプリでロゴ画像を長押し →「名称変更」で **`logo.png`** にする
   （写真アプリにある画像は、共有 →「"ファイル"に保存」で先に「ファイル」アプリへ移します）
3. Safari で GitHub のリポジトリを開き、「Add file」→「Upload files」→ `logo.png` を選んで「Commit changes」
4. 1〜2 分待ってからアプリを開き直す

- 登録されると、ビデオモードの画面右下にロゴが表示されます。**画面に見えているものが、そのまま録画されます。**
- 未登録のあいだは、画面上部に黄色い「ロゴ未登録」の案内が出ます（録画はできますが、ロゴは入りません）。
- `logo.webp` `logo.jpg` という名前でも読み込みます（透明背景が使えるのは PNG と WebP です）。
- ロゴを差し替えるときは、同じ名前でアップロードし直してください。

## 5. 設定の変更（config.js）

GitHub で `config.js` を開き、鉛筆マークで編集 →「Commit changes」で反映されます。

| 項目 | 初期値 | 内容 |
|---|---|---|
| `logo.position` | `'bottom-right'` | ロゴの位置（右下 / 左下 `'bottom-left'` / 右上 `'top-right'` / 左上 `'top-left'`） |
| `logo.widthRatio` | `0.30` | ロゴの横幅（動画の短い辺に対する割合） |
| `logo.maxHeightRatio` | `0.20` | ロゴの高さの上限 |
| `logo.marginRatio` | `0.035` | 端からの余白 |
| `logo.opacity` | `1` | 透明度（0.5 で半透明） |
| `video.width / height` | `1920 / 1080` | 希望解像度（iPhone が対応する範囲で自動調整） |
| `video.frameRate` | `30` | 希望フレームレート |
| `video.bitsPerSecond` | `10000000` | 画質（10Mbps） |
| `video.chunkSeconds` | `0` | 録画の途中で区切って退避する間隔（秒）。`0` = 区切らない（推奨）。1 以上にすると録画中に落ちても途中まで復元できるが、iPhone では区切りのたびに映像が飛ぶ |
| `video.maxSeconds` | `600` | 1 回の録画上限（10 分）。達すると自動停止して確認画面へ |
| `photo.logo` | `false` | 写真にもロゴを入れる場合は `true` |
| `guide.bottom` | `0.86` | 縦動画でガイド線の枠にする範囲（上から何割までか）。解析画面で下のボタンに隠れない範囲に合わせている |
| `guide.head` / `guide.feet` | `0.30` / `0.78` | 枠の中での「頭の線」「足元の線」の高さ（枠の上端 = 0、下端 = 1） |
| `guide.defaultOn` | `true` | 初めて使うときにガイド線を表示しておくか |
| `autoRotate` | `false` | `false`：画面左上のボタンで縦 / 横を選ぶ（iOS の確認は出ない）。`true`：本体の傾きで自動判定する（起動のたびに、最初の撮影で iOS から「動作と方向」の許可を求められる） |
| `autoRotateReverse` | `false` | 自動判定（`autoRotate: true`）で、横に構えて撮った動画が上下逆さまに保存される場合だけ `true` にする |
| `autoShare` | `true` | 撮影後に共有メニューを自動で開く。`false` にすると「写真に保存」を押すまで開かない |
| `defaultMode` | `'video'` | 起動時のモード |

アイコンを変えたいときは、同じサイズ・同じファイル名（`icon-180.png` など）の画像で上書きし、ホーム画面のアイコンを一度削除して追加し直してください。

## 6. アプリの更新方法

1. GitHub で変更したいファイルを上書きアップロード（または編集）する
2. 1〜3 分待つ
3. アプリを完全に閉じて（アプリスイッチャーで上にスワイプ）開き直す

電波があるときは毎回最新のファイルを取りに行く仕組みなので、古いプログラムが残り続けることはありません。
圏外のときだけ、前回読み込んだファイルで起動します。

## 7. 採用した方式と理由

**「カメラ映像＋ロゴ」をリアルタイムで合成しながら録画する方式**です。

- カメラ映像を 1 コマずつ canvas に描き、その上にロゴを描く
- その canvas の映像とマイクの音声を合わせて MediaRecorder で録画する（iPhone では MP4 / H.264 + AAC）

| 検討した方式 | 判断 | 理由 |
|---|---|---|
| **撮影しながら合成（採用）** | ○ | 停止した瞬間にロゴ入り動画が完成する。待ち時間ゼロ。音声は撮影時のものがそのまま入り、再生速度も変わらない |
| 撮影後に動画を再生し直して合成 | × | 動画と同じ長さの待ち時間が発生する。iPhone の Safari では再生中の動画から音声を取り出して録り直す手段が安定しない |
| WebCodecs で 1 コマずつ再エンコード | × | 動画ファイルの分解・組み立てに外部ライブラリが必要。iOS の版による対応差が大きく、長い動画でメモリ不足になりやすい |
| ffmpeg.wasm などの動画変換ライブラリ | × | 数十 MB の読み込みが必要で、iPhone ではメモリ不足で落ちやすい。GitHub Pages では高速動作に必要な設定ができない |

依頼書では「撮影後に合成」となっていましたが、iPhone で安定して動き、操作回数も待ち時間も最小になるため、撮影中に合成する方式にしています。結果（保存される動画にロゴが焼き込まれている）は同じです。

**データを失わないための仕組み**

- 録画が終わった時点で、完成した動画を iPhone 内の一時保管場所（IndexedDB）に保存します。保存操作の前にアプリを閉じてしまっても、次に開いたときに確認画面で復元されます。
- 録画の途中では区切って退避しません。実機の動画を解析したところ、1 秒ごとに区切るたびに映像が約 0.4 秒飛び、カクカクして見える原因になっていたためです。そのため、**録画中にアプリが落ちた場合、その録画は復元できません**（`config.js` の `video.chunkSeconds` を 1 以上にすると途中退避に戻せますが、映像が飛びます）。
- 確認画面の動画・写真は、「撮影に戻る」を押すまで消しません。保存操作をしていない場合は、戻る前に確認が出ます。
- 保存できたかどうかはアプリ側から確認できないため、「保存完了」とは表示しません。

## 8. 制約（Web アプリであることによるもの）

| 項目 | 内容 |
|---|---|
| 写真アプリへの直接保存 | できません。必ず「写真に保存」→ 共有メニュー →「ビデオを保存 / 画像を保存」の操作が必要です |
| 写真の解像度 | カメラ映像の 1 コマを保存するため、約 200 万画素（1920×1080）です。純正カメラ（1200 万画素以上）より低くなります。高精細な写真が必要なときは純正カメラをお使いください |
| 動画の画質 | 最大 1080p / 30fps を希望値にしています。4K・60fps・スローモーション・手ぶれ補正・望遠（2× 以上）は対象外です |
| インカメラ | ビデオモードの画面は「録画される映像そのもの」を表示するため、鏡像（左右反転）になりません。保存される写真・動画も反転しません |
| 録画中の画面ロック・アプリ切り替え | 映像が止まるため、その時点で録画を終了して確認画面に進みます |
| 録画中に本体を回した場合 | 動画の縦横は録画開始時の向きで固定されます（途中で回すと上下または左右に黒帯が入ります） |
| カメラの許可 | iOS の仕様で、起動のたびに許可を求められることがあります |
| 縦 / 横の向き | 画面左上のボタンで手動で選びます。本体の傾きから自動で判定する方法もありますが、iOS が起動のたびに「動作と方向」の許可を求めるため、標準ではオフにしています（`config.js` の `autoRotate` で切り替え可能）。ボタンを「縦向き」のまま本体を横に構えると、縦向きの動画として保存されます |
| 本体を横に構えた時の画面 | 映像とロゴは正しい向きで表示・保存されますが、ボタンや文字は縦向きのままです（「画面縦向きのロック」がオンの場合） |
| 共有メニューの自動表示 | iOS が自動表示を認めない場合は開きません。そのときは「写真に保存」を押してください |
| 長時間録画 | 動画は保存するまでメモリ上にあるため、上限を 10 分にしています。レッスン用途では 1 本 1〜2 分以内を推奨します |
| 対応環境 | iPhone の Safari（iOS 16 以降を想定）。LINE などのアプリ内ブラウザでは動かない場合があります |

1. アプリを開くとカメラが映る
2. ビデオモードで画面右下にロゴが見える
3. 10 秒ほど録画 → 停止 → 確認画面で**映像・ロゴ・音声**が再生できる
4. 停止すると共有メニューが自動で開く（開かなければ「写真に保存」を押す）→「ビデオを保存」を選ぶ
5. **写真アプリで、その動画がロゴ入り・音声付き・正しい向きで再生できる**
6. 左上のボタンを「横向き」にして本体を横に構え、3〜5 を確認する。写真アプリで横長の動画として、上下正しく、ロゴが右下に正しい向きで入っていれば OK
7. インカメラでも 3〜5 を確認する
8. 写真モードで撮影 →「写真に保存」→「画像を保存」→ 写真アプリで確認
9. 1〜2 分の動画でも 3〜5 が問題ないか、映像がカクつかないかを確認する

うまくいかない項目があれば、画面上部の「GOLF GUTS CAMERA」をタップして表示される情報（バージョン・カメラ映像・録画形式など）と、iPhone の機種・iOS のバージョンを添えてお知らせください。

## 10. 困ったとき

| 症状 | 対処 |
|---|---|
| カメラが映らない | 「設定」→（「アプリ」→）「Safari」→「カメラ」「マイク」を「確認」または「許可」にして、アプリを開き直す |
| 「音声なし」と表示される | 上と同じ場所で「マイク」を許可する |
| ロゴが出ない | ファイル名が `logo.png`（すべて半角小文字）か確認。アップロード後 1〜2 分待ってアプリを開き直す |
| 映像がカクつく・本体が熱い | `config.js` の `width: 1920, height: 1080` を `width: 1280, height: 720` に変更する |
| 再生の音が小さい | 本体の音量ボタンで上げる。消音モードも確認する |
| 共有メニューに「ビデオを保存」が出ない | 共有メニューを下にスクロールして探す。それでも無い場合は確認画面の情報を添えてお知らせください |
| 「ロゴ入り録画ができませんでした」と出る | アプリを開き直す。直らない場合は、案内の「ロゴなしで録画する（非常用）」で撮影自体は続けられます |
| 更新したのに変わらない | アプリを完全に閉じて開き直す。数分待ってからもう一度試す |
| 横に構えたのに縦動画になる | 画面左上のボタンが「縦向き」のままになっています。押して「横向き」（黄色）にしてから撮影する |
| 横に構えた動画が上下逆さまになる | 本体を逆向きに構えています。横向きのときは、本体の上側を左に向けて構える（画面のロゴが正しい向きに見える状態が正解） |
| 縦で撮ったのに横長の動画になる | 左上のボタンが「横向き」のままになっています。押して「縦向き」に戻す |
| 「.5 / 1×」のボタンが出ない・押しても広角にならない | 画面上部の「GOLF GUTS CAMERA」をタップし、「超広角」と「カメラ一覧」の行を確認してお知らせください（機種ごとの違いを調整します） |
